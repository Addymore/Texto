# Contributing to Texto

Use the included Gradle wrapper with JDK 17 and Android SDK 34. Run `:presentation:assembleDebug :common:testDebugUnitTest`; use `build-texto.ps1` on Windows. Keep the GPL notices and upstream attribution.

For changes to privacy or deletion, test receive paths, notifications, search, widgets, shortcuts, direct links, backgrounding, backups and MMS parts. Use only synthetic messages in a disposable emulator. The separate androidTest instrumentation is never shipped in the app APK; `DEVICE-TESTS.md` covers device acceptance.

Open issues and pull requests in [Addymore/Texto](https://github.com/Addymore/Texto). Include reproduction steps, app version, phone/Android version and expected behavior. Remove personal message data from evidence. State clearly whether a result was unit-tested, emulator-tested or checked on a carrier-connected device.

Keep unrelated upstream behavior intact. New user-visible Texto strings are currently English; localization contributions are welcome. For upstream-only changes, consider contributing to [QUIK](https://github.com/quik-sms/quik).
