# Optional OEM-inspired visual profiles

Texto stays unchanged until the user chooses Apply in Themes → OEM-inspired presets. Profiles coordinate visual choices; they do not install manufacturer apps, fonts or system services, and do not claim exact regional or version-specific replicas.

| Profile | Header and list | Messages and navigation |
|---|---|---|
| Samsung | Large centered reachable header, clean flat list | Blue sent / neutral received, asymmetric rounded corners, flat navigation |
| ColorOS/OxygenOS | Bold left header, compact one-line previews, soft cards | Green sent / neutral received, soft bubbles, floating navigation |
| Pixel | Compact heading, clean avatar-led list | Blue sent / neutral received, pill bubbles, flat Material-inspired navigation |
| Xiaomi | Large left header, compact flat list | Blue sent / neutral received, asymmetric rounded corners |
| Nothing | Monospaced heading and names, outlined cards | Monochrome bubbles, red controls, squared navigation |
| Motorola | Compact heading, clean list | Teal sent / neutral received, rounded Material surfaces |
| Honor | Centered reachable heading, rounded cards | Blue sent / neutral received, floating navigation |
| vivo | Bold left heading, rounded cards | Purple sent / neutral received, compact floating navigation |

Apply saves the original card settings, density, previews, badge style, accent and dynamic-color state. Switching profiles retains that first snapshot. Restore reinstates absent preferences as absent as well as saved values. Existing 1.7.0 five-field snapshots are extended without overwriting their original values. Personal images, title/motto and privacy settings are not changed.

Reference boundaries: [Samsung's official messaging page](https://www.samsung.com/us/apps/samsung-messages/) now documents the US transition to Google Messages; this profile intentionally evokes the familiar Samsung layout, not a claim about a new native One UI 9 messaging app. [OPPO's official ColorOS design presentation](https://www.oppo.com/en/coloros13/) provides general visual design context. Regional app availability and OEM versions differ; profiles are labeled inspired accordingly.
