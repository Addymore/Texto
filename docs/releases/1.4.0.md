# Texto 1.4.0 — Consistent themes and smoother conversations

Fixes phone numbers, email addresses and web links becoming dark on dark message bubbles. Incoming and outgoing message text and links now use a foreground color chosen for their actual background, including AMOLED and custom accents. Private conversations receive the same fix.

Settings and scheduled-message cards now share conversation styling. Controls and date/time pickers follow the selected accent on Android 11+, and About links to Texto. SMS scrolling avoids attachment work; MMS adapters and unchanged avatars are reused.

Selection highlights and handles also use resolved colors. Links remain underlined and keep their existing actions and confirmation settings.

Install **Texto-1.4.0-debug.apk** over your existing Texto development build. It uses the same application ID and local debug signing certificate. Source and checksums are included.

Validation: build, 19 JVM tests and 40 Android emulator contrast cases passed, alongside selected-accent, Settings-card and scheduling-picker checks. Actual OnePlus frame pacing and a full mixed-media regression remain device checks.

This remains a development preview. See [validation](https://github.com/Addymore/Texto/blob/master/VALIDATION.md) for checks and device limitations. RCS is not implemented.
