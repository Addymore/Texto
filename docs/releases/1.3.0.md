# Texto 1.3 — One look, public and private

Texto 1.3 brings the normal inbox layout into private messages and expands the theme controls. Built on QUIK, developed by **Addymore**.

## What changed

- **Matching conversation layouts:** private lists use the same avatars, cards, timestamps, totals and unread indicators as the public inbox. Private SMS/MMS opens in the normal conversation screen and inherits its themes.
- **More personal themes:** eight palettes and custom hex accents; live sample previews; neutral, tinted or outlined cards; compact through airy spacing; hidden or one-to-three-line previews; avatar/count toggles; unread dots or badges; direct appearance, AMOLED and text-size controls.
- **Discreet privacy notices:** public tips and lock confirmations no longer explain the private entry gesture. PIN/strong biometric authentication remains in place.
- **Protection fixes:** private conversation windows retain their secure flag when resumed; theme headings and controls have clearer contrast.

The protected 30/60/90-day recycle bin, number-level privacy rules, spam controls and inherited QUIK messaging workflows remain available.

## Download and install

Download **Texto-1.3.0-debug.apk** below and make Texto the default SMS app. This is a **development preview**, debug-signed, with application ID `app.texto.sms.debug`. Source and SHA-256 checksums accompany the APK. Keep a verified backup before replacing your primary SMS workflow.

## Validation and current limits

The Android build and 19 JVM tests pass. Android 14 emulator instrumentation also passes shared private layouts/themes, public exclusion, secure-window protection, private search and background relocking. See [VALIDATION.md](https://github.com/Addymore/Texto/blob/master/VALIDATION.md) for emulator results and checks still requiring a physical device. Real OnePlus 13 fingerprint sensing/frame pacing, carrier SMS/MMS, Android 16/16 KB compatibility and full legacy-feature regression remain unverified. RCS is not implemented.

Private storage is protected within Texto, not encrypted in Android's shared message provider. Recycle-bin records remain in that provider until expiry; Android may defer cleanup.
